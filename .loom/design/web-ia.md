## 8. 两根支柱(用户原话钉板)

**导入导出=用户的安装仪式**:ST 每个对象都带它(预设/主题/卡/WI/背景/
Persona)。我们的设计:每对象就地保留 import/export + 设置·数据下统一
"导入导出中心"(批量/格式总览/URL导入),移动端卡导入保 PNG/URL。

**开发者工具=生态引水渠**:Luker 已埋半成品(request inspector/
存储检查器/调试导出/生成任务/自profiling),新结构提成一等公民——
web 导航加「诊断」域或生成配置内 tab:上一轮发给 LLM 的完整 prompt
查看器(=request inspector 精神)、WI 激活轨迹、token 计数、生成任务
监视、golden-diff 结果、存储检查、插件 degraded 诊断。服务"调卡人/
插件作者/我们自己"三个角色。

## 9. 舒适原则(用户直觉/舒适度/入门轻松度,具体可验收)

**入门**:第一次打开不该看见空控制台——引导三步:①连API源(或扫码)②导入第一张卡(拖PNG/贴URL/选示例)③进聊天。空库时导入按钮占C位不缩角落;每步可跳过,跳过后入口仍在显眼处。

**直觉**:
- 导入是通用手势:拖PNG/贴URL,在任何页面都接住(不是只有角色页)
- 每页只回答一个问题:"我现在能干什么"——主操作≤2个且视觉上最重
- 日常动作≤2击:聊天里 swipe/重生成/发送常显;管理里 保存/导入 常显
- 消灭"互斥隐藏块"(ST API provider 病):源选一次,该源参数就地展开,不切整页结构
- 高频深埋点上浮:Author's Note/CFG/logprobs 从"没入口"→会话抽屉直达;Prompt Manager→生成配置内二级面板;Sync→设置·数据一级项
- 搜索万能:设置/条目/消息/预设 统一  唤起(抄 ST settingsSearch 但全域)

**舒适**:
- 排版旋钮长在阅读现场:字号/行距/字距/密度在聊天页右上小条调,不是三层深设置(存服务端全端同步,D-013)
- 深色默认;长文自动折叠+展开动画;流式逐块追加不reflow;CJK混排间距
- 消息操作:hover显二级/长按菜单(移动),常态只剩 swipe 计数
- 空态必教:每个空列表说"怎么填进来"(拖卡到这/点这导入)
- 回得去:层级深的地方必有面包屑或"返回列表"常驻

**不打扰**:toast 非阻塞不堆叠;生成中输入框可用(排队下一条);错误说人话+给"怎么办"链到对应修复位。

## 14. IA v3 桌面化 + 对话渲染器缝(评审通过的结构)

**壳结构(ChatGPT 桌面端式,已获认可)**:
- 原生 titlebar(菜单+窗口控件)+ 46px activity rail + 240px 二级侧栏(每域内容)+ 底部 24px 状态栏

**概念解耦/合并(评审裁决)**:
- 扩展+插件 → 合并为「扩展」域:插件/正则/快捷回复/注入/卡资产 同域不同类别
- 注入统一:Guide(dsh-tavern)+作者注+CFG/Logprobs+全局注入提示词 = 同一概念×作用域(本局/卡/全局),本局面板收"本局注入",全局注入在扩展域
- 状态板 = 一种面板(系统面板),MVU 状态板进面板列表,不另开概念
- 媒体 = 同一概念三作用域:会话画廊 / 卡媒体 / 消息附件
- 本局设置 ≠ 全局设置(解耦,ST 用户最易混);正则 = 一个引擎多作用域(scope 徽章)

**对话渲染器 = seam:conversationRenderer(F-024 级)**
