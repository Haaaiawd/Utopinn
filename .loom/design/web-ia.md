## 1. ST UI 面全量盘点(输入源)

ST 主界面结构 = 顶栏 icon 排 + 左侧角色抽屉 + 中央聊天 + 浮层面板:

| ST 面 | 内容 | 使用频率 | 归类建议 |
|---|---|---|---|
| AI Response Configuration | API源选择/预设/采样滑条/上下文长度 | 高 | → 生成配置·连接与采样 |
| API Connections | 各 provider 密钥/URL/模型 | 中 | → 设置·API源与密钥 |
| Advanced Formatting | instruct模式/上下文模板/Prompt Manager(几十条可拖项) | 中(调卡时高) | → 生成配置·提示词 |
| User Settings | 主题/语言/杂项行为开关 | 低 | → 设置·外观与行为 |
| Backgrounds | 聊天背景图 | 低 | → 设置·外观 |
| Extensions 面板 | QR/正则/TTS/图生/向量等扩展设置 | 中 | → 扩展域 |
| Persona | 用户人设(名+描述+头像) | 中 | → 库·人设 |
| 角色抽屉 | 角色列表/搜索/导入导出/创建/群聊 | 高 | → 库·角色卡 |
| World Info 面板 | 世界书文件+条目编辑器(键/次键/位置/深度/概率/递归/角色过滤/timed) | 高(调卡) | → 库·世界书 |
| 角色编辑器 | 定义/first_mes/备选问候/性格/场景/示例/creator notes/内嵌WI/内嵌正则脚本/标签 | 高(制卡) | → 库·角色卡·编辑器 |

| Quick Replies | 快捷回复按钮+编辑器 | 中 | → 扩展(官方重实现) |

| 密钥管理 | API key 存储 | 低 | → 设置·API源与密钥 |
| 数据 | 导入导出/备份/存储统计 | 低 | → 设置·数据 |

## 5. 明确不做(ST 里有、我们砍掉或换位的)

- 顶栏 icon 汤 → 侧导航分组(上面)

## 8. 两根支柱(用户原话钉板)

**导入导出=用户的安装仪式**:ST 每个对象都带它(预设/主题/卡/WI/背景/
Persona)。我们的设计:每对象就地保留 import/export + 设置·数据下统一
"导入导出中心"(批量/格式总览/URL导入),移动端卡导入保 PNG/URL。

**开发者工具=生态引水渠**:Luker 已埋半成品(request inspector/
存储检查器/调试导出/生成任务/自profiling),新结构提成一等公民——
web 导航加「诊断」域或生成配置内 tab:上一轮发给 LLM 的完整 prompt
查看器(=request inspector 精神)、WI 激活轨迹、token 计数、生成任务
监视、golden-diff 结果、存储检查、插件 degraded 诊断。服务"调卡人/
插件作者/我们自己"三个角色。
