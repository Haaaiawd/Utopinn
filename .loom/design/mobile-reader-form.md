> 注(D-020/021,2026-11-04):本稿是 **UX 目标稿,仍然有效**——「会话=书/楼层=段落流/呼出 chrome/语义分章」的形态裁决不随实现栈变化;但实现地基已从 Expo 改判 fork IReader(见 mobile-fork-ireader.md),且形态属持续研究线,不封顶。

> Apple Books/Wattpad/AO3 实测 + RP 先例(彩云小梦/Character.AI/ST 引号色)。

## 0. 架构落位(Cordis 约束)

阅读器形态 = **渲染器 + 宿主 chrome 的组合**,不是新的数据语义:

- `prose` 渲染器(conversation-renderers.md §2 已定 V1 默认)在移动端的
  实例就是「小说流」;`bubble` 保留为一键切换的形态,任何卡/用户可回退。
- 宿主(apps/mobile)负责:点中央呼出/收起 chrome、书写层(你的回合)、
  阅读设置(Aa)、章节导航、书签。这些全是「手势+版式」,数据面不动。
- `MessageViewModel` 已带 `swipes/activeSwipe/streaming/reasoning/receipts/
  displayContent/hidden`,RendererActions 已带 swipe/edit/regen/branch——
  **协议零新增**;`TypingSettings` 直接承载阅读设置;`StageScheme` 供卡声明
  纸色/字体 token。
- CardApp 面板不占底 tab,收进阅读页 chrome「…」/章末卡(panelBridge
  管线不变,TASK-009 照原协议做)。

## 1. IA(底导航四 tab → 三级阅读路径)

```
书架(对话聚合=书) / 角色(书库) / 面板 / 我的
书架行 → 书页(详情) → 阅读器(沉浸正文)
```

- **书架**(默认落点):单行列表为主,行=一次会话=一本书。
  行解剖:3:4 竖版封面(角色立绘) + 书名(chatName) + 副行(最新段落
  首句截断) + 徽标(「进行中」「N 段未读」)。智能筛选预置:进行中 /
  有更新 / 角色分组宫格。「养肥」= 攒了 N 段没看。
- **角色**:现有角色列表升级,点进 = 该角色的「作品列表」(会话)+
  卡详情入口。
- **书页**:大幅角色图 + chatName + 「继续阅读」主 CTA(落点=上次
  阅读位置) + 卡描述摘要 + 章节目录 + 次操作(从头读/分支/角色卡/导出)。

## 2. 阅读器(核心面)

### chrome 进出(中文阅读器肌肉记忆)

- 正文全屏零 chrome;**单击中央 ~45% 区域**呼出/收起(<200ms 淡入);
  左右缘 ~28% 点击=上/下一章(滚动模式下默认关,可开)。
- **顶栏**:返回 + 书名 + 当前章名 + 「…」(形态切换/分支/角色卡/导出)。
- **底栏双行**:行1=上一章/进度条(拖动跳章)/下一章;
  行2=目录/排式(prose⇄bubble)/Aa 设置/夜间。
- **手势**:长按段=操作菜单(重写此段/编辑/从此分叉/复制);下拉=钉书签;
  (v2 捏合=字号)。
- **目录抽屉**:左缘滑出,章列表带当前章高亮+已读灰。

### 正文映射(RP→小说,方案 A)

| RP 元素 | 小说呈现 |
|---|---|
| 楼层正文 | 连续散文段落(段首缩进 2 字,markdown 直接排版) |
| user 段 | 左缘 2px 发丝线(accent 30% 透明),首行可缩进;**无「你说:」前缀** |
| 群聊 | 段首 12px/ink3 署名,同人连续段合并署名(sameSpeakerAsPrevious) |
| `*动作*` | 斜体 + 90% 墨色;`[*内心*]` 更弱 |
| `"对话"` | 引号高亮三档:关/单色/分人配色(分人=实验开关,v1 单色) |
| swipe | 段尾「✦N稿」角标 → 半屏候选卡(60字预览+时间戳,选定稿=actions.swipe) |
| 生成中 | **墨迹书写**:末段逐字淡入(打字机定速,R5 允许),段前 6px 墨点呼吸;interrupted 残稿虚线下划+50% 透明 |
| receipts/MVU | 章末「作者有话说」位,正文 token 派生色(晋江教训:勿固定色) |
| reasoning | 「作者草稿」折叠块,不进正文 |
| hidden/system | 幕间灰字小注,可折叠 |

### 你的回合(composer,呼出式——否决底部常驻)

- 沉浸态正文末尾虚线占位「——轮到你落笔」/右下半透明笔尖 FAB。
- 点开=**半屏书写层**(微信读书「写想法」位):输入区+快捷符
  `*`动作 `"`台词 `(`OOC;发送后收起,你的段落落版,墨迹开始写 AI 段。
- 键盘弹起自动垫高最新段。

### 章节(语义切片——不按楼层分章,方案 B 已否决)

- 启发式分章:时间间隔(>4h)/场景词/字数节点(~4-6k);章名=首段首句截12字(远期 AI 拟题)。
- 用户可手动钉书签位;进度条按字数拉通。

## 4. 阅读设置面板 v1 子集

亮度(含跟随系统)/字号滑块 A-A+/行距四档/字体三选/背景5色/翻页
(滚动默认·覆盖备选,**仿真不做**——流式追加场景)/对话高亮/user 标识开关/
页内章节名显示开关。字距/段距/边距/页眉槽位 → v2。
设置全部写 `TypingSettings`+本地持久化,卡可经 `StageScheme` 声明默认主题。

## 5. 风险与待定

- **避头尾/标点悬挂**:RN Text 近似有瑕疵;v2 如要高保真需自排版引擎
  (已知技术风险项,先接受瑕疵上线)。
- **分人对话配色召回率**:卡文署名习惯杂,先单色上线,分人做实验开关。
- **书架聚合粒度**:v1 按会话=书;若用户更想要「书=角色」,chat 变
  「卷」,目录结构需再议(调研已标注为待用户确认项)。
- **沉浸默认态**:进阅读屏默认全屏无 chrome,首次进入给一次性「点中央
  呼出工具」toast。
- **章名自动拟题**远期可接服务端生成,不进 v1。

## 6. 验收锚点

- 书架→书页→阅读器三级路径通;点中央呼出/收起 <200ms。
- prose 渲染器在 RN 落地:swipe 角标/墨迹生成/段尾操作长按全通。
- Aa 面板五主题+字号+行距实时生效;夜读低对比不与非阅读深色混。
- 「你的回合」半屏层发送→落版→墨迹接写全链;bubble 形态可切回。
- CardApp 面板经原 bridge 在 chrome 内挂载(TASK-009 不变)。
